# GUÍA DE ESTILO DE MARCA - TAXI TRUCK

## 1. IDENTIDAD DE MARCA
**Concepto**: Fusión de rapidez (taxi) y carga (camión). 
**Valores**: Rapidez (90 min), Simplicidad (sin trámites), Accesibilidad (WhatsApp/Tlf), Eficiencia (Tarifas fijas).

## 2. PALETA DE COLORES
| Color | HEX | Uso |
| :--- | :--- | :--- |
| **Negro Intenso** | `#000000` | Logotipo, texto principal, solidez. |
| **Amarillo Vibrante** | `#FFD000` | Acentos, CTAs, energía, visibilidad. |
| **Blanco** | `#FFFFFF` | Fondos, contraste. |
| **Gris Medio** | `#808080` | Texto secundario, bordes. |
| **Gris Claro** | `#F5F5F5` | Fondos alternativos. |

## 3. TIPOGRAFÍA
- **Títulos**: Montserrat Black / Bebas Neue. (Mayúsculas, negrita extrema, kerning comprimido).
- **Cuerpo**: Roboto / Open Sans. (Regular, limpio).
- **Estilo**: Industrial, moderno, fuerte.

## 4. ELEMENTOS VISUALES
- **Logo**: Círculo negro contenedor, texto central, silueta de camión amarillo a la derecha.
- **Texturas**: Metal industrial, asfalto, líneas de velocidad.
- **Patrones**: Rayas diagonales amarillas/negras (45°) para advertencias o acentos.

## 5. PRINCIPIOS DE DISEÑO
- Minimalista y funcional.
- Espacios blancos generosos.
- Sensación de movimiento (dinamismo).
- Iconografía lineal (2-3px).

## 6. TONO Y VOZ
- Directo, ágil y profesional.
- Mensajes clave: "Un camión disponible en solo 90 minutos".

## 7. ELEMENTOS A EVITAR (PROHIBIDO)
- ❌ Tipografías Serif.
- ❌ Degradados complejos o 3D exagerado.
- ❌ Amarillo como fondo principal en bloques grandes.
- ❌ Lenguaje técnico excesivo.
